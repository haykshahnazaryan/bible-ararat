# Աստուածաշունչ Մատեան — «Արարատ» թարգմանութիւն

A single-file, offline-friendly web reader for the complete Armenian Bible in the
**«Արարատ» (Ararat)** translation — all 65 books, 1,163 chapters, with verses
and section headings.

🔗 **Live site:** https://haykshahnazaryan.github.io/bible-ararat/

## Features

- **Full text** — both testaments (Հին / Նոր Կտակարան), every book and chapter.
- **Book grid sidebar** — abbreviated book tiles in two testament sections, with a
  drill-down to a chapter-number grid (like the source app).
- **Reader** — chapter heading and verses with numbered markers; previous/next
  chapter navigation across book boundaries.
- **Search** — filter books by name or abbreviation.
- **Light / dark themes** — the choice is remembered between visits.
- **Self-contained** — everything (text + styles + script) lives in a single
  `index.html`; no server or build step needed to view it.

## Source & attribution

The scriptural text is the **«Արարատ» translation** published by the
**Bible Society of Armenia** (<https://biblesociety.am>). The Ararat translation
dates from the late 19th century and the translation text itself is in the public
domain. This project is a non-commercial reading interface; all credit for the text
belongs to the Bible Society of Armenia.

## Rebuilding from source

The site is generated by the scripts in [`src/`](src/):

1. `parse_structure.py` — parses the testament → book → chapter structure → `structure.json`
2. `build_bible.py` — cleans the fetched chapter HTML into `bible_data.json`
3. `generate_html.py` — renders the final reader from `bible_data.json`

To regenerate the page from the included data:

```bash
cd src
python3 generate_html.py      # writes armenian-bible-stone.html
cp armenian-bible-stone.html ../index.html
```

(The raw scraped chapter cache is not committed; `build_bible.py` expects a
`src/chapters/` directory of fetched chapter files if you want to rebuild the data
from scratch.)
